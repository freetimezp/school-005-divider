# Linework — Lesson 005

A beginner-friendly HTML and CSS lesson about horizontal dividers, the `<hr>` element, borders, margins, and padding.

## Features

- Distinct editorial design using terracotta, lavender, sage, and ink
- Semantic HTML examples using `<hr>`
- Interactive divider style selector
- Adjustable line thickness and width
- Adjustable vertical spacing
- Multiple accent color options
- Live CSS preview and copy button
- Visual explanations of margin, padding, and border
- Responsive desktop and mobile layouts
- Reduced-motion support
- Vanilla HTML, CSS, and JavaScript

## Learning objectives

After completing this lesson, learners should be able to:

1. Explain the purpose of the `<hr>` element.
2. Distinguish a thematic break from a decorative border.
3. Change border style, color, and thickness with CSS.
4. Understand the difference between margin and padding.
5. Use spacing to improve the readability of a layout.
6. Experiment with CSS values and reuse generated code.

## Run locally

Open `index.html` in a browser. No build tools or JavaScript libraries are required.
